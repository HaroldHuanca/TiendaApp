## 🎓 Cómo Modificar

### Agregar Nuevo Componente
1. Crea la clase en `estilos.css`
2. Usa variables CSS para colores
3. Asegura responsiveness
4. Usa clases utilidad existentes

### Cambiar Espaciado
Edita variables en `:root`:
```css
--spacing-md: 1rem;  /* Cambiar aquí */
```

### Agregar Nuevo Breakpoint
Agrega al final de `estilos.css`:
```css
@media (max-width: 480px) {
  /* Estilos para pantallas muy pequeñas */
}
```
